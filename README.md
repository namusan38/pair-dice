# ペア・ダイス

5個のサイコロを振って、2つずつのペアの合計を記録用紙にチェックしていくロール&ライト系のダイスゲームです。ブラウザだけで遊べて、スマホにも対応しています。全員共通のオンラインランキング付き。

## 遊び方

1. 「サイコロを振る」で5個のサイコロを振ります。
2. 捨てる1個をタップします。
3. 残り4個の組み合わせ方(最大3通り)から1つ選ぶと、2つのペアの合計(2〜12)にチェックが入ります。各ボタンには、その手を選んだ時の得点の増減が表示されます。
4. これを繰り返し、捨てサイコロのどれかが8個たまったらゲーム終了です。

### ルール

- 捨てサイコロの目は3種類まで。3種類が決まった後は、その目しか捨てられません。該当する目がない時は好きな1個を捨てられ、記録はしません。
- 各数字のマスは「マイナス」と「プラス」に分かれています。

| 数字 | マイナスのマス | プラスのマス |
|---|---|---|
| 2・3・11・12 | 3個 | 6個 |
| 4・5・9・10 | 4個 | 6個 |
| 6・7・8 | 5個 | 6個 |

- 各数字の得点
  - チェック0個:0点
  - マイナスのマスにチェックがある間:−200点
  - プラスのマスに入ったら:1個ごとに下表の点数(6個まで)

| 数字 | 2・12 | 3・11 | 4・10 | 5・9 | 6・8 | 7 |
|---|---|---|---|---|---|---|
| 1個あたり | 100 | 70 | 60 | 50 | 40 | 30 |

- 独自ルール:1ゲームに2回だけ、捨てる前なら5個まとめて振り直せます。

### その他の機能

- **効果音**:右上のスピーカーボタンでオン/オフを切り替えられます(設定は端末に保存)。
- **最初からやり直す**:サイコロのボタンの下にあります。誤操作を防ぐため、1回押すと確認表示に変わり、3秒以内にもう一度押すとリセットされます。

ベースはシド・サクソンの「ソリティア・ダイス」です。

## 公開手順

### 1. ランキング用スプレッドシートを用意する

1. Googleスプレッドシート「ペア・ダイス ランキング」を開きます(1行目に `日時 / 名前 / スコア / 手番` の見出しがあればOK)。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身を全部消して、`Code.gs` の内容を貼り付けて保存します。
4. 右上の **デプロイ → 新しいデプロイ** を選びます。
   - 種類:**ウェブアプリ**
   - 次のユーザーとして実行:**自分**
   - アクセスできるユーザー:**全員**
5. 「デプロイ」を押し、Googleアカウントへのアクセスを許可します(「このアプリは確認されていません」と出たら「詳細」→「(安全ではないページ)に移動」)。
6. 表示された **ウェブアプリのURL**(`https://script.google.com/macros/s/.../exec`)をコピーします。

### 2. URLをゲームに設定する

`config.js` の次の行に、コピーしたURLを貼り付けます。

```js
  RANKING_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
```

URLを `config.js` に分けてあるので、今後 `index.html` を新しい版に差し替えてもURLを貼り直す必要はありません。

空のままだとランキングは「準備中」と表示され、ゲームだけ遊べます。

### 3. GitHub Pages で公開する

1. GitHubで新しいリポジトリ(例:`pair-dice`)を **Public** で作ります。
2. `index.html`・`config.js`・`README.md` をアップロードします(`Code.gs` は置いても置かなくても構いません)。
3. リポジトリの **Settings → Pages** で、Source を **Deploy from a branch**、Branch を `main` / `/ (root)` にして保存します。
4. 1〜2分後、`https://ユーザー名.github.io/pair-dice/` で遊べるようになります。

## ランキングの管理

- 登録されたスコアはスプレッドシートにそのまま1行ずつたまります。
- 不正なスコアや不適切な名前は、その行を削除するだけでランキングから消えます。
- 上位20件を表示します(件数は `Code.gs` の `TOP_N` で変更できます)。
- 誰でも登録できる仕組みなので、スコアの改ざんを完全には防げません。身内や小規模で楽しむ前提です。
- `Code.gs` を書き換えた時は **デプロイ → デプロイを管理 → 編集(鉛筆)→ バージョン:新バージョン** で更新してください(URLは変わりません)。

## 保存されるデータ

- ブラウザ:ベストスコア、途中経過、前回入力した名前(その端末だけ)
- スプレッドシート:登録時の日時・名前・スコア・手番
